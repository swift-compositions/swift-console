# swift-console

Use this package when a command-line program needs to color its output only as far as the terminal allows, or to read key, mouse and paste events from a terminal in raw mode. Start from `Console.Capability.detect(stream:)` and `Console.Style` for output, and from `Console.Input.withEvents(stream:configuration:_:)` for input. If you only need to parse terminal bytes or build mode escape sequences without any I/O, use swift-terminal.

## Laws

- `Console.Capability.detect(stream:)` reads the process environment and decides in this order. `NO_COLOR` set gives `.none`, even with `FORCE_COLOR` set. Without `FORCE_COLOR`, a stream that is not interactive gives `.none`. `COLORTERM` of `truecolor` or `24bit` gives `.full`. An unset or empty `TERM` gives `.basic` when `CI`, `GITHUB_ACTIONS`, `GITLAB_CI` or `FORCE_COLOR` is set, and `.none` otherwise. `TERM` of `dumb` gives `.none`. A `TERM` containing `256color` or `256-color` gives 256 colors with cursor control and the alternate screen. A `TERM` containing `xterm-direct`, `iterm2` or `vte` gives `.full`. Any other `TERM` gives `.basic`.
- Only whether a variable is set counts, not its value, except for `COLORTERM` and `TERM`.
- Outside Apple platforms and Linux no stream counts as interactive, so detection gives color only with `FORCE_COLOR`.
- When the capability has no color, `Console.Style.sequence(for:)` and `Console.Style.resetSequence(for:)` are empty and `Console.Style.apply(to:capability:)` returns the text unchanged. A style with no colors and no attributes also returns the text unchanged, with no reset added.
- A style is one SGR sequence: attributes in ascending code order, then the foreground, then the background. The reset is SGR 0, which clears everything, not just this style.
- Palette colors are written as they are at every color level. Below 256 colors, an extended color becomes its index modulo 8 among the eight basic colors, so its brightness is lost. Below true color, an RGB color maps to the 6×6×6 cube of the 256-color palette, each channel scaled by truncation. Below 256 colors, an RGB color maps to the 16 basic colors: a channel above 127 turns that color bit on, an average above 127 makes it bright, and a color whose channels are all below 64 becomes black or bright black.
- `Console.Input.withEvents(stream:configuration:_:)` enters raw mode, then enables mouse tracking (any event, SGR encoding), bracketed paste and the Kitty keyboard protocol as configured. On exit it disables them in reverse order and restores the terminal, whether the body returns or throws. Failures during that cleanup are discarded. If enabling a mode fails, raw mode is restored before the error is thrown.
- The event function returns nil when the stream reaches end of input. A partial escape sequence is held until more bytes arrive, so a lone ESC press waits for further input. Any other parse failure is thrown and ends the loop.
- `Console.Output.error(_:)` writes the text to standard error as is, with no newline added.
